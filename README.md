# SkillSense 🚀

**SkillSense** is an AI-powered skill intelligence platform designed to help professionals identify, analyze, and manage their career growth. By aggregating data from CVs, performance reviews, and online profiles, SkillSense provides a comprehensive view of your professional DNA.



## ✨ Key Features

- **🧠 AI Skill Extraction**: Automatically extract skills, proficiency levels, and experience from uploaded CVs and documents using Google Gemini AI.
- **📊 Skill Profile & Visualization**: View your skills in a dynamic radar chart, categorized by Technical, Soft Skills, Leadership, and more.
- **🔍 Opportunity Analyzer**: Compare your current skill set against job requirements to identify gaps and strengths.
- **🔮 Future Skills Forecaster**: Stay ahead of the curve with AI-driven predictions on emerging skills in your industry.
- **💬 AI Career Coach**: Interact with a built-in chatbot for personalized career advice and skill development tips.
- **📄 Professional CV Export**: Generate and download a polished PDF version of your skill profile.
- **🎥 Demo Recorder**: Record and manage skill demonstrations to provide tangible proof of your expertise.

## 🛠️ Tech Stack

- **Frontend**: [React 19](https://react.dev/), [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **AI Engine**: [Google Gemini API](https://ai.google.dev/) (`@google/genai`)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **PDF Generation**: [jsPDF](https://github.com/parallax/jsPDF)
- **Visuals**: Custom SVG Radar Charts & Immersive 4D UI Effects (Rain, Starry Sky)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn
- A Google Gemini API Key

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/username/skillsense.git
   cd skillsense
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

## 📖 Usage

1. **Welcome Page**: Log in or create a profile to access your personalized dashboard.
2. **Data Sources**: Upload your CV, paste performance reviews, or link professional profiles.
3. **Analyze**: Click "Analyze" to let the AI process your data and build your skill profile.
4. **Explore**:
   - Use the **Dashboard** for a high-level overview.
   - Visit the **Profile** tab to manage and refine your skills.
   - Use **Opportunities** to see how you match up against target roles.
   - Chat with the **AI Assistant** for real-time guidance.
